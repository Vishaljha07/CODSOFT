# 🎬 Movie Genre Classification

## 📌 Internship Task

**Internship:** CodSoft Machine Learning Internship

**Task:** Movie Genre Classification

---

## 📖 Project Description

This project builds a Machine Learning model that predicts the genre of a movie based on its plot summary or textual description.

The model uses TF-IDF Vectorization to convert text into numerical features and Logistic Regression for genre classification.

---

## 🛠 Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Logistic Regression
- Jupyter Notebook

---

## 📂 Dataset

Dataset contains movie titles, genres, and descriptions.

- Total Records: 54,214
- Total Genres: 27

---

## ⚙️ Project Workflow

1. Load and preprocess dataset
2. Create DataFrame from text dataset
3. Split dataset into training and testing sets
4. Convert text into numerical features using TF-IDF
5. Train Logistic Regression model
6. Evaluate model performance
7. Predict movie genres from custom descriptions

---

## 📊 Model Performance

Accuracy Achieved: **58.85%**

---
