# Customer Churn Prediction

## 📌 Internship Task

**Internship:** CodSoft Machine Learning Internship

**Task:** Customer Churn Prediction

---

## 📖 Project Description

This project predicts whether a customer is likely to leave a company or continue using its services based on customer information and banking details.

A Logistic Regression model is used to analyze customer behavior and predict churn.

---

## 🛠 Technologies Used

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
- Logistic Regression

---

## 📂 Dataset Information

Dataset contains customer banking information such as:

- Credit Score
- Geography
- Gender
- Age
- Balance
- Number of Products
- Active Membership Status
- Estimated Salary

Total Records: **10,000**

---

## ⚙️ Project Workflow

1. Load Dataset
2. Data Preprocessing
3. Feature Selection
4. Train-Test Split
5. Model Training
6. Model Evaluation
7. Customer Churn Prediction

---

## 📊 Model Performance

**Accuracy Achieved: 80.15%**
