## 📖 Project Description

This project is a Machine Learning classification task that detects whether an SMS message is Spam or Not Spam.

The model classifies messages into:

* Spam
* Not Spam (Ham)

---

## 📊 Dataset

* Dataset Name: Spam SMS Dataset
* File: spam.csv
* Features:

  * SMS Messages
* Target:

  * Spam / Ham

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter Notebook

---

## 🤖 Machine Learning Algorithm

* Multinomial Naive Bayes

---

## ⚙️ Steps Performed

1. Imported required libraries
2. Loaded and explored the dataset
3. Preprocessed the data
4. Converted text into numerical format using TF-IDF
5. Split data into training and testing sets
6. Trained the Naive Bayes model
7. Evaluated the model using accuracy score
8. Tested the model with sample messages

---

## ✅ Model Performance

* Achieved good accuracy on the test dataset
* Successfully detected spam and non-spam messages

---

## ▶️ How to Run the Project

1. Open `spam_1st.ipynb`
2. Run all cells sequentially
3. Ensure `spam.csv` is in the same directory
